Personal projects

E-commerce E2E Test Suite

An end-to-end test suite for an online shop, built layer by layer, with a data-quality layer on top. Everything runs with one Docker command and in GitHub Actions, one parallel job per layer.

  • UI: Playwright and Page Object Model against saucedemo, with typed test data.
  • API: CRUD, JSON Schema contracts, headers and negative cases (400, 401, 404, 405, 409, 422).
  • Auth: storageState per role, a role × endpoint permission matrix, forged and expired tokens.
  • Database: after each API write, the row is read straight from PostgreSQL and checked.
  • Data quality: checks across validity, completeness, accuracy, timeliness, consistency and uniqueness. Each check is tested by injecting a defect.
